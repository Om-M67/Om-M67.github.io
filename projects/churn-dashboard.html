Interactive Churn Dashboard

live dashboard

Overview

A working interactive dashboard — KPI cards, churn-rate breakdowns by contract and internet type, and a live region filter that recalculates every chart in real time. Built on a 1,000-row practice dataset to demonstrate dashboard design and data modeling end-to-end.

This is separate from the pandas-based Telco Churn analysis, which uses the full 7,043-customer dataset — this one is purpose-built to pair with the SQL Churn Queries project below.
