Write-up

KelogsDojo was a team project (six engineers) to build a strategic card game in Java from the ground up — game rules, turn logic, and an AI opponent — using Apache Maven to manage dependencies and the build process consistently across everyone's machines.

Working on a team of this size meant the usual collaborative-engineering challenges: dividing the game into components multiple people could work on independently (game state, rule enforcement, AI logic) without constantly blocking each other, then integrating and debugging those pieces together. My focus was on the AI opponent — building difficulty tiers that required understanding the existing game logic well enough to modify its decision-making without breaking rule enforcement elsewhere in the codebase.

This project's value on a resume is less about the specific card game and more about what it demonstrates: working inside an existing multi-contributor codebase, using a real build tool (Maven) rather than ad-hoc scripts, and being able to trace and modify application logic — skills that translate directly to functional troubleshooting and support work in a team engineering environment.
