SQL Churn Queries

Overview

A set of MySQL queries against a 1,000-row practice telecom churn dataset — joins, aggregations, a subquery, and two window functions — surfacing which customer segments churn most. This dataset also powers the Interactive Churn Dashboard project.

  • Month-to-month customers churn at 51.9%, versus 16.7% for two-year contracts.
  • Fiber-optic customers churn more than DSL customers in every region, despite similar pricing.
  • All four regions run above a 30% churn-rate target, with North highest at 40.1%.

Tools

MySQL Joins Window functions Subqueries

Write-up

This project runs six SQL queries against a 1,000-row practice telecom dataset in MySQL — covering aggregation, a join against a lookup table, a subquery, and two window functions — to demonstrate SQL fluency independent of the pandas-based analyses elsewhere in this portfolio.

The queries surface which customer segments churn most (contract type and internet type are the strongest signals), flag which regions are running above a churn-rate target using a joined lookup table, find high-value customers who churned anyway using a subquery, and rank customers by lifetime value within each region using a window function — the kind of query patterns that come up constantly in real churn/retention analysis work.

Example query

SELECT contract_type,
       COUNT(*) AS total_customers,
       ROUND(100.0 * SUM(CASE WHEN churn='Yes' THEN 1 ELSE 0 END)
             / COUNT(*), 1) AS churn_rate_pct
FROM customers
GROUP BY contract_type
ORDER BY churn_rate_pct DESC;
