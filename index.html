SQL Churn Queries

write-up available

A set of MySQL queries against a practice telecom churn dataset — joins, aggregations, a subquery, and two window functions — feeding the dashboard above. 

SELECT contract_type,
       COUNT(*) AS total_customers,
       ROUND(100.0 * SUM(CASE WHEN churn='Yes' THEN 1 ELSE 0 END)
             / COUNT(*), 1) AS churn_rate_pct
FROM customers
GROUP BY contract_type
ORDER BY churn_rate_pct DESC;
